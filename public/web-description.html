Generování popisku v2

Moderní editor pro produktové popisky: vstupy vlevo, výstup a náhled vpravo. Připravené pro rychlé vložení na web.

Vstupní data produktu

Primární jsou ID produktu, název, krátký a dlouhý popis. Ostatní pole jsou volitelná.

Po vyplnění formuláře klikni na generování. V1 vždy generuje CZ (language_id=1) i SK (language_id=2).
